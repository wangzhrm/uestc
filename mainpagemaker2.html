How to Use This Tool

  1. Set your page title and banner image (optional)
  2. Create chapters to organize your content
  3. Add topics under each chapter
  4. Add resources (documents, links) to topics
  5. Drag and drop to reorder resources within and between topics
  6. Click "Export HTML" to generate the HTML code
  7. Copy the code and host it on GitHub Pages
  8. NEW: Import existing HTML to update your content

GitHub Publishing Instructions

  1. Create a new repository on GitHub
  2. Create a new file named "index.html"
  3. Paste the generated HTML code into this file
  4. Commit the file to your repository
  5. Go to repository Settings → Pages
  6. Set source to "Deploy from a branch" and select your main branch
  7. Your document list will be live at: https://[your-username].github.io/[repository-name]
